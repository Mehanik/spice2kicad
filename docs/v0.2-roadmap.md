# v0.2 implementation roadmap — structure-first placer

> Derived from `docs/target-architecture.md` (the 4-track research + red-team
> synthesis). Direction: **replace the flat `bands→layers→SA` skeleton with a
> Sugiyama-layered, flow-directed seed; generalise phase-4.5 to bounded
> joint-pose repair; lean on the invariant/ratchet harness (the moat).**
> Idiom cells are REJECTED (Spike-0 confirmed common_emitter's bends are
> inter-block seams). R-A locality is at its frontier — do not re-litigate.
>
> **Execution discipline (non-negotiable, from the project record):**
> verifiers-first (instrument before you change behaviour); each behaviour
> change is a layout change under the ADR-16 baseline-diff protocol
> (regenerate `baseline_lock`, V16 (B,J) non-increasing per fixture, table in
> the commit message); zero-slack ratchets only ratchet down; never weaken a
> gate or raise a budget to force green; commit each green step.

## Milestone A — Instrumentation (verifiers-first; pure adds; no behaviour change)

Land the metrics that will *judge* the architecture work, so B/C/D are
guarded by measurement, not vibes. Each step: measure master → record the
per-fixture high-water mark → commit. No production code changes.

- **A1. Q3 flow-monotonicity metric + ratchet.** Fraction of signal-DAG
  forward edges drawn left→right (and supply→ground top→bottom). Instruments
  Wall-1/Wall-2 work. New test file; per-fixture ratchet at measured master.
- **A2. Round-trip connectivity certificate.** Reconstruct nets from emitted
  geometry (union coincident wire endpoints + pin coords + glyph flags),
  partition, compare to the source netlist partition — a whole-file V11
  (Weave §verification). Output-side gate; strengthens the baseline protocol.
- **A3. Q5 mutual-alignment near-miss metric + ratchet.** Count component
  pairs within a small threshold of sharing an axis but not exactly sharing
  it (a human would snap them). Per-fixture high-water mark.
- **A4. Q6 balance metric + ratchet.** Content density variance across a
  coarse page grid + centroid offset from usable-area centre. Per-fixture.

(Q1 grouping cohesion/separation and Q2 idiom-edit-distance need cluster
structure that only Milestone C produces — deferred to Milestone E.)

## Milestone B — Signal-flow foundation (behaviour change; ADR-16 each)

- **B1. DC-path device-direction inference (computed, UNCONSUMED first).** An
  analysis pass over the resolved netlist producing per-terminal current-flow
  direction (MOS drain→source, BJT collector→emitter, source +→−) and a
  *directed* signal graph. Land it with unit tests, NOT yet wired into
  layering → pure add, empty baseline diff. (Ref: TUM ESFG dissertation.)
- **B2. Feedback-arc MARKING (not reversing).** Replace `layers.rs:383
  break_cycles`'s silent edge reversal with greedy-feedback-arc-set that
  *marks* feedback edges exempt. Consume the marking so feedback no longer
  distorts the forward layering. Behaviour change → ADR-16 protocol; Q3
  (A1) should improve or hold. (Rust: `petgraph::greedy_feedback_arc_set`.)
- **B3. Wire DC-path direction into layer assignment**, replacing the
  `no_source_fallback` heuristic path where the DC-path graph gives a real
  flow. Behaviour change → ADR-16; A1 Q3 must improve, no Tier-0/1 regress.

## Milestone C — Layered seed (higher-risk; staged, measured, reversible)

- **C1. lcapy-style decoupled per-axis longest-path spacing** as the seed's
  metric assignment (min-distance edges + `stretch`/slack). Formalises "X
  slack / Y meaning". Behind measurement; keep the SA polisher on top.
- **C2. Crossing-minimisation sweep** (median/barycenter, Brandes–Köpf
  coordinate assignment) — the one Sugiyama phase we do poorly. Crossing
  ratchet must fall or hold.

## Milestone D — The Wall-1 fix (highest owner-visible value)

- **D1. Generalise phase-4.5 from orientation-only to bounded JOINT-POSE
  local repair** (position + orientation + mirror over a small neighbourhood),
  still gated by the real router + lexicographic tuple + severed/V11/overlap/
  V12 guards. Retires the `COUT`/`RIN`-drawn-vertical defects without idiom
  cells. (= the long-deferred ADR-19 M6, now the centrepiece.)

## Milestone E — Human-level structural metrics (needs C's structure)

- **E1. Q1 functional grouping (cohesion/separation)** and **Q2 idiom-canonical
  edit-distance**, once clusters/idioms are represented. Verifiers-first.

## Gating

A → B → (C, D can proceed in parallel once B lands) → E. C and D are
higher-risk; do not start them until Milestone A's instruments are green on
master, so their behaviour changes are judged by the new metrics. Any step
that trips a Tier-0/1 ratchet without a single owner-signed global-improvement
escape is reverted, not forced.

## Findings / status log

- **A1–A4 LANDED** (verifiers): Q3 flow-monotonicity, round-trip
  connectivity, Q5 alignment, Q6 balance (as a degeneracy tripwire — CoV is
  noisy on small fixtures, so it is informational, not a hard ratchet).
- **B1 LANDED** (`flow.rs`, computed-unconsumed): DC-path directed flow graph
  + feedback-arc marking, byte-identical output.
- **B2/B3 ATTEMPTED, REVERTED — the flow model has almost no lever on the
  current fixture suite** (measured, two variants):
  1. **Every fixture already takes `no_source_fallback`** — all stimulus
     sources carry `;@ ignore` and are dropped before resolve, so
     `break_cycles`' feedback *reversal* is DEAD CODE on every real fixture
     (only synthetic `layers.rs` unit tests exercise it). The real lever lives
     entirely inside `no_source_fallback`.
  2. **Reseeding layers from the flow graph regressed V16** on the two
     *non-feedback* fixtures (`common_emitter` B 4→6, `named_rails` 1→3) — a
     fresh spacing-derived layering loses the hand-tuned BFS quality ("Y
     spacing is meaning").
  3. **The canonical feedback case (the op-amp) is a `.subckt` sheet
     instance** that `flow.rs` treats as directionless, so its feedback
     resistor is never marked → the flow work is a no-op there. Only
     `multivibrator` has one marked arc, and suppressing it moves nothing.

  **Strategic consequence:** the Sugiyama-flow architecture (research item 1)
  cannot demonstrate value on the current suite, which is (a) small and
  hand-tuned to near-optimal, (b) source-ignored (so no rooted flow), and
  (c) feedback-hidden-behind-subckts. The zero-slack ratchets on those tuned
  fixtures then *actively block* any reseed that changes them — the
  local-optimum freeze applied to the redesign itself. **The prerequisite is
  fixtures the current placer does POORLY on** (multi-stage amps, active
  filters with visible feedback, un-ignored flow), where the new architecture
  has room to prove itself and drive ratchets DOWN. Options, in order:
  - **F0 (new prerequisite): expand the benchmark** — add harder fixtures with
    real, visible feedback and un-ignored signal flow; record their (poor)
    baseline ratchets. This is "fixtures-before-intervention" and unblocks
    B/C/D by giving them a lever.
  - **B1′: sheet-instance flow edges** — make `signal_flow` emit a
    port-direction DC-path edge for `.subckt` instances (`inp/inn → out`) so
    op-amp feedback closes a real loop and gets marked. Cheap; unblocks the
    opamp lever for a retried B2/B3.
  - **Promote D (phase-4.5 joint-pose repair)** — it targets a REAL current
    defect (`COUT`/`RIN` drawn vertical) and is self-contained (does not need
    the absent flow lever); the red-team called it the highest owner-visible
    value. Best near-term ratchet-mover on the *existing* suite.
