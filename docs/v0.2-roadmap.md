# v0.2 implementation roadmap — structure-first placer

> Derived from `docs/target-architecture.md` (the 4-track research + red-team
> synthesis). Direction: **replace the flat `bands→layers→SA` skeleton with a
> Sugiyama-layered, flow-directed seed; generalise phase-4.5 to bounded
> joint-pose repair; lean on the invariant/ratchet harness (the moat).**
> Idiom cells are REJECTED (Spike-0 confirmed common_emitter's bends are
> inter-block seams). R-A locality is at its frontier — do not re-litigate.
>
> **Execution discipline (non-negotiable, from the project record):**
> verifiers-first (instrument before you change behaviour); each behaviour
> change is a layout change under the ADR-16 baseline-diff protocol
> (regenerate `baseline_lock`, V16 (B,J) non-increasing per fixture, table in
> the commit message); zero-slack ratchets only ratchet down; never weaken a
> gate or raise a budget to force green; commit each green step.

## Milestone A — Instrumentation (verifiers-first; pure adds; no behaviour change)

Land the metrics that will *judge* the architecture work, so B/C/D are
guarded by measurement, not vibes. Each step: measure master → record the
per-fixture high-water mark → commit. No production code changes.

- **A1. Q3 flow-monotonicity metric + ratchet.** Fraction of signal-DAG
  forward edges drawn left→right (and supply→ground top→bottom). Instruments
  Wall-1/Wall-2 work. New test file; per-fixture ratchet at measured master.
- **A2. Round-trip connectivity certificate.** Reconstruct nets from emitted
  geometry (union coincident wire endpoints + pin coords + glyph flags),
  partition, compare to the source netlist partition — a whole-file V11
  (Weave §verification). Output-side gate; strengthens the baseline protocol.
- **A3. Q5 mutual-alignment near-miss metric + ratchet.** Count component
  pairs within a small threshold of sharing an axis but not exactly sharing
  it (a human would snap them). Per-fixture high-water mark.
- **A4. Q6 balance metric + ratchet.** Content density variance across a
  coarse page grid + centroid offset from usable-area centre. Per-fixture.

(Q1 grouping cohesion/separation and Q2 idiom-edit-distance need cluster
structure that only Milestone C produces — deferred to Milestone E.)

## Milestone B — Signal-flow foundation (behaviour change; ADR-16 each)

- **B1. DC-path device-direction inference (computed, UNCONSUMED first).** An
  analysis pass over the resolved netlist producing per-terminal current-flow
  direction (MOS drain→source, BJT collector→emitter, source +→−) and a
  *directed* signal graph. Land it with unit tests, NOT yet wired into
  layering → pure add, empty baseline diff. (Ref: TUM ESFG dissertation.)
- **B2. Feedback-arc MARKING (not reversing).** Replace `layers.rs:383
  break_cycles`'s silent edge reversal with greedy-feedback-arc-set that
  *marks* feedback edges exempt. Consume the marking so feedback no longer
  distorts the forward layering. Behaviour change → ADR-16 protocol; Q3
  (A1) should improve or hold. (Rust: `petgraph::greedy_feedback_arc_set`.)
- **B3. Wire DC-path direction into layer assignment**, replacing the
  `no_source_fallback` heuristic path where the DC-path graph gives a real
  flow. Behaviour change → ADR-16; A1 Q3 must improve, no Tier-0/1 regress.

## Milestone C — Layered seed (higher-risk; staged, measured, reversible)

- **C1. lcapy-style decoupled per-axis longest-path spacing** as the seed's
  metric assignment (min-distance edges + `stretch`/slack). Formalises "X
  slack / Y meaning". Behind measurement; keep the SA polisher on top.
- **C2. Crossing-minimisation sweep** (median/barycenter, Brandes–Köpf
  coordinate assignment) — the one Sugiyama phase we do poorly. Crossing
  ratchet must fall or hold.

## Milestone D — The Wall-1 fix (highest owner-visible value)

- **D1. Generalise phase-4.5 from orientation-only to bounded JOINT-POSE
  local repair** (position + orientation + mirror over a small neighbourhood),
  still gated by the real router + lexicographic tuple + severed/V11/overlap/
  V12 guards. Retires the `COUT`/`RIN`-drawn-vertical defects without idiom
  cells. (= the long-deferred ADR-19 M6, now the centrepiece.)

## Milestone E — Human-level structural metrics (needs C's structure)

- **E1. Q1 functional grouping (cohesion/separation)** and **Q2 idiom-canonical
  edit-distance**, once clusters/idioms are represented. Verifiers-first.

## Gating

A → B → (C, D can proceed in parallel once B lands) → E. C and D are
higher-risk; do not start them until Milestone A's instruments are green on
master, so their behaviour changes are judged by the new metrics. Any step
that trips a Tier-0/1 ratchet without a single owner-signed global-improvement
escape is reverted, not forced.

- **B2/B3 ATTEMPTED, REVERTED — the flow model has almost no lever on the
  current fixture suite** (measured, two variants):
  1. **Every fixture already takes `no_source_fallback`** — all stimulus
     sources carry `;@ ignore` and are dropped before resolve, so

     entirely inside `no_source_fallback`.
  2. **Reseeding layers from the flow graph regressed V16** on the two

  cannot demonstrate value on the current suite, which is (a) small and
  hand-tuned to near-optimal, (b) source-ignored (so no rooted flow), and

  fixtures the current placer does POORLY on** (multi-stage amps, active
  filters with visible feedback, un-ignored flow), where the new architecture
  has room to prove itself and drive ratchets DOWN. Options, in order:

  - **B1′: sheet-instance flow edges** — emit a port-direction DC-path edge

    (Would start from the deleted `flow.rs` — see the B1 status entry below
    for the commit to recover it from.)
  - **Promote D (phase-4.5 joint-pose repair)** — it targets a REAL current
    defect (`COUT`/`RIN` drawn vertical) and is self-contained (does not need

  **Defect 1 — `shunt_feedback_amp`: a Tier-0 base/emitter short (V11).**
  Default conversion exits non-zero because the CLI's own post-emit
  connectivity check rejects the output: source nets `b` and `e` are merged
  (`net in the source but split in the schematic: {"CE.0","Q1.2","RE.0"}`
  and `{"CIN.1","Q1.1","RB.1","RF.1"}`). The router logs `conflict: net
  index 0 has endpoint conflicts left after 6 resolve iterations` first —
  the V11/V12 cascade gives up and leaves two nets geometrically
  coincident. *Deterministic*: three `--no-layout-cache` runs, byte-
  identical output, same non-zero exit. *Localised to the stage-3 SA, not
  the router and not phase 4.5*: a `--refine-iterations` sweep converts
  **cleanly** at 0, 1, 20, 40, 60, 80, 100 and 400 and **fails** at 150 and
  200 (200 is the default); `--no-refine` is clean. So it is not a monotone
  "more annealing is worse" gradient but one specific SA end-state whose
  placement the router cannot legalise — the placement-vs-router
  disagreement of MEMORY "flow-orientation wall", here escalated from a
  Tier-2 aesthetic disagreement to a **Tier-0 correctness failure**. That
  makes it the strongest evidence yet for ADR-15's "SA as polisher"
  direction, and a ready-made acceptance test for any replacement.

  **Defect 2 — `two_stage_amp`: ~112 s to convert, and it is CPU, not
  memory.** It converts *correctly* (exit 0, connectivity clean) but takes
  ~112 s where the median v0.1 fixture takes 0.4 s and the slowest takes
  4.5 s; registering it across ~15 verifiers would add roughly 25
  CPU-minutes to every suite run. *It is NOT the OOM defect the earlier F0
  attempt reported.* That attempt recorded ">8 GB of virtual memory,
  nondeterministically OOM-killed"; measured here by sampling
  `/proc/<pid>/status` across a full conversion, **VmPeak is 25.8 MB** and
  the conversion completes under a `ulimit -v 8388608` cap every time.
  (The earlier figure came from the `ed51164` ADR-19 M4 tree, since
  reverted — another entry for MEMORY "verify what a number measures".)
  *First-look diagnosis — a bounded product, not unbounded growth.*
  `--no-refine` takes the conversion from 112 s to 0.43 s, and that flag
  ablates two passes (the SA and phase 4.5). Phase 4.5 uses the **real
  router** as its oracle, re-routing the whole sheet once per candidate
  orientation, and all its loops are capped (`refine.rs`: `MAX_SWEEPS = 4`,
  `MAX_ACTIVE = 4`, `MAX_COMBINATIONS = 512`) — so this is not the
  "unbounded router segment growth" class. It is the **product** of ~10³
  trial routes and a per-route cost that is itself elevated here: one route
  costs ~50 ms (`--no-refine --no-verify` is 0.09 s for the whole
  conversion) and the router logs `cross-net overlap: nets 3/1 unresolved
  by single-track jog`, i.e. every trial route runs the V11/V12 cascade to
  exhaustion; 10³ × 50 ms ≈ the observed time. Corroborating that reading,
  the `--refine-iterations` sweep is **non-monotone** (0 → 16 s, 1 → 17 s,
  20 → 5 s, 200 → 125 s): cost tracks *which placement the SA lands on*,
  not the iteration count. Fixing it is out of F0 scope; the plausible
  levers are (a) memoising phase 4.5's per-candidate route measurements and
  (b) an early-out in the conflict cascade once a candidate is already
  worse than the incumbent — neither changes emitted geometry.

### F3 — both Tier-0 locks discharged; the router, not the placer

**Status: landed. `tests/f0_defects.rs` now holds no locks at all.**

The two Tier-0 defect locks above — Defect 1 (`shunt_feedback_amp`) and
Defect 3 (`sallen_key_driven`) — were **one router defect**, and neither
was in the placer. Full diagnosis in `docs/layout-adr.md` ADR-24; the
short form:

* A 3-pin net's exact Hwang tree puts its Steiner point at the
  coordinate-wise **median** of the pins. On both fixtures that median
  landed on a *foreign net's pin*.
* `conflict::resolve_conflicts` correctly wants the tree off that
  coordinate, but its `jog_endpoint_at` rewrites **one incident segment
  per pass**, and its destination depends on the segment's axis. Applied
  to a degree-3 vertex it sends the three legs to three different
  coordinates. `cleanup::trim_whiskers` then deletes the orphan —
  including the segment on the net's own pin.
* Separately, the detour passes create cross-net endpoint coincidences
  that nothing re-checks: `resolve_conflicts` ran only *before* them.

Fixed by (a) moving a degree-≥3 tree vertex off a foreign pin at
construction time — the line `conflict::corner_degree`'s own doc already
draws, and the exact gap `try_alt_l_corner` / `try_u_detour_l_pair`
document themselves as leaving — and (b) re-running `resolve_conflicts`
after the detour passes. Both fixtures now convert and are graded.

**Three corrections this forces to the text above.**

1. **Defect 1's "localised to the stage-3 SA" reading is wrong**, and so
   is ADR-20's successor diagnosis that pinned it on the owner-gated R-5
   rail-pin defect. R-5 is untouched — `shunt_feedback_amp` still trips
   `v14_rail_pin_faces_rail`, now as a registered XFAIL — and the fixture
   converts anyway. ADR-20 read phase 4.5's `severed = 2` on the
   *incoming* placement as a placer fact; phase 4.5's oracle **is the
   real router**, so it was a router fact. `baseline_lock` proves it: 247
   of 247 pre-existing rows byte-identical, no element moved.
2. **Defect 3's `--refine-iterations` sweep does not say what it was read
   as saying.** "The bare seed is already Tier-0 broken" is true of the
   emitted geometry and false of the placement: the seed placement is
   fine and the router broke it. The sweep is still a good instrument —
   it is what isolated a router bug from a placer one — but it is not
   evidence about a deterministic constructive seed.
3. **`*@port` is not "purely cosmetic", and that is a second defect.**
   The masking control arm is explained, not mysterious: `*@port` is read
   by `layers::no_source_fallback` *and* by `idioms::signal_net_depth`,
   which seeds its flow BFS **only** from declared input ports, with a
   fallback that requires the input net to touch exactly one element.
   Drawing the source gives `in` two elements, so on `sallen_key_driven`
   the fallback does not fire and `signal_net_depth` returns an **empty
   map** — every series element directionless. Adding `*@port in=input`
   restores the roots and moves the placement; it never fixed anything.
   That is a latent-input defect in the root heuristic, not evidence of
   ADR-17's "global, unattributable consequences". It is open: see
   ADR-24 § "Open items".

**Blast radius.** Confined to `crates/spice-route/`. `baseline_lock`
gains 35 rows (the two promoted fixtures) and loses none. Eleven of the
thirteen previously-emitted `.kicad_sch` are byte-identical;
`two_stage_amp` loses one wire segment (56 → 55) at identical total wire
length, identical junctions, identical poses, identical V16 `(B, J)`. No
budget rose.
